# Proxied downloads read storage in parallel ranges and honour Range

`@actions/cache` fetches a non-Azure `archiveLocation` with one plain GET (`downloadCacheHttpClient`); its concurrent, ranged downloader runs only for `*.blob.core.windows.net` hosts. BuildKit's `type=gha` importer reads each blob as one sequential stream and reopens it with an open-ended `Range: bytes=N-` when it seeks, rejecting any response whose `Content-Range` does not start at `N`. A proxied download is therefore exactly as fast as one storage GET stream, and some object stores cap a single stream far below the network (MinIO erasure sets spanning sites, high-latency S3 endpoints). Direct downloads do not help: the runner then makes the same single GET against the store.

The server now reads a merged object as `DOWNLOAD_CONCURRENCY` ranged requests of `DOWNLOAD_CHUNK_BYTES` and streams them to the client in order. The head window is forwarded as it arrives, so time to first byte and the idle-socket timeout behave as before; later windows are buffered, bounding memory per download to about concurrency × chunk size. The next window starts only when the head window has been handed to the client, so a slow client throttles storage reads. A failed window is retried from its first undelivered byte, and destroying the response aborts every in-flight request. The default concurrency of 1 keeps today's single stream.

The download route also reports `Content-Length` and `Accept-Ranges`, and answers a single-range `Range` request on a merged object with `206` and `Content-Range` (`416` when unsatisfiable). Entries still stored as Parts are streamed whole, as before; multi-range and malformed headers get a full `200`, which RFC 9110 permits.

Adapters opt in through `getObjectSize` and a `range` argument to `createDownloadStream`; S3, GCS and the filesystem driver implement both. Parallel reads apply to merged objects only. The first download of an unmerged entry still tees Parts sequentially into the response and the merge; `EAGER_MERGE` avoids that path.
